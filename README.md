
# EnergyGuard AI

End-to-End Machine Learning System for Oil & Gas Well Anomaly Detection

## Project Overview

EnergyGuard AI is a machine learning application designed
to detect abnormal operating conditions in oil and gas wells.

The project demonstrates an end-to-end ML engineering
workflow, from synthetic data generation to cloud deployment.

## Objectives

- Generate realistic synthetic well production data
- Simulate normal and abnormal operating conditions
- Train and evaluate anomaly detection models
- Build automated ML pipelines
- Develop a FastAPI prediction service
- Create an interactive Streamlit dashboard
- Deploy the application to the cloud

## Anomaly Types

1. Pressure loss
2. Production disruption
3. Sensor malfunction

## Technology Stack

- Python
- NumPy and Pandas
- scikit-learn and PyTorch
- MLflow
- FastAPI
- Streamlit and Plotly
- Docker
- GitHub Actions

## Project Status

Under development.

The initial application uses synthetic well data.
